## 1. Verification Philosophy & Execution Commands

Foreal-Estate combines open geospatial convenience scoring, statistical asking-vs-AVM property comparisons under a hard `< 50` calls/month provider ceiling, and runtime Gemini narrative grounding. Naive "happy-path" unit tests miss the highest-impact failure modes: silent weight renormalization on API timeouts, edge clipping at region boundaries, `google_places_context` license leakage, AVM midpoint overclaiming when asking price sits inside `[avmLow, avmHigh]`, budget resets across container restarts, stale out-of-order UI overwrites, prompt-injected LLM hallucinations, and accidental secret exposure.
